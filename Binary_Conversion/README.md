<h1>Binary Conversion</h1>

<p>A simple script that runs in the command line.<br>
Prompts user to input the kind of value they would like to convert<br>
Then converts it using FUNctions and MATH!</p>

# Conversion Types

## Binary
### -> Decimal
### -> Hexadecimal

## Decimal
### -> Binary
### -> Hexadecimal

## Hexadecimal
### -> Binary
### -> Decimal
