# Number Converter
 
A small Python script that converts numbers between decimal, 8-bit binary, and 2-character hexadecimal. The conversions are done by hand (no built-in `bin()` or `hex()`) as practice.
 
## Requirements
 
Python 3.10 or newer. No extra libraries needed.
 
## Usage
 
```
python decimal_convert.py
```
 
Pick what to convert from, pick what to convert to, then enter your number. Enter `q` to quit.
 
## Limits
 
- Decimal: whole numbers from 0 to 255
- Binary: exactly 8 digits (1s and 0s)
- Hex: exactly 2 characters (00 to FF)
